# 03_grant-drafting — draft from evidence, not imagination

One job: turn one owner-approved opportunity into a complete draft grounded in New World Kids records and HSI documents.

## Inputs
- Working: `../02_grant-research/output/shortlist.md`
- Reference: `../_shared/mission.md`
- Reference: `../_shared/legal-and-fiscal-sponsor.md`
- Working: funder guidelines/questions, program budget, current proof records, and required attachments.

## Process
1. Copy the funder's actual questions and constraints into the working draft.
2. Build a claim ledger before prose: each material statement gets a source or is marked `NEEDS SOURCE`.
3. Draft directly to the funder's priorities without changing New World Kids' mission to chase the grant.
4. Build the budget from real planned costs; distinguish program costs from HSI/admin treatment when applicable.
5. Run a final unsupported-claim, deadline, attachment, word-count, and duplicate-submission check.

## Outputs
- `output/claim-ledger.md`
- `output/grant-draft.md`
- `output/attachments-checklist.md`

## Human check
Owner verifies facts, commitments, budget, requested amount, and named people. Fix every `NEEDS SOURCE` item before the draft moves to HSI review.
