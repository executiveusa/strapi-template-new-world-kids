# New World Kids ICM

This folder is the agent-readable operating map for New World Kids. It is a router, not a knowledge dump.

## Rules

1. Never store passwords, session cookies, recovery codes, API keys, or payment credentials in Git.
2. Public claims must map to evidence already accepted in the repository.
3. HSI review is mandatory before any grant submission.
4. GrantStation must not be scraped or controlled by an automated agent without written permission from GrantStation.
5. Fundraising copy and funding-source outreach must follow HSI/fiscal-sponsor requirements.
6. Human approval is required at the explicit gate in each stage contract.
