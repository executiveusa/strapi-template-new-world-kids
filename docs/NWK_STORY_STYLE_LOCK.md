# New World Kids — Story + Visual System Lock

## Status
LOCKED for the current reduction/build pass.

## Governing idea
Tell the real story with the least possible explanation.

## Visual rules
- Use ASC3ND-style editorial rigor and documentary pacing, but do **not** copy ASC3ND typography.
- New World Kids keeps its own type system.
- Full-bleed or large-format media over UI containers.
- Thin rules, strong spacing, asymmetry, and negative space.
- No cards unless a real content need requires one.
- No pill-heavy interface language.
- No decorative motion.
- Photography and footage carry the emotional weight.
- Copy stays short, concrete, and evidence-led.

## Story separation rule
Proyecto Indigo Azul and Seattle are different communities with different challenges. Never merge them into one implied program history.

### Proyecto Indigo Azul
