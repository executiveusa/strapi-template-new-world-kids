## 1. Mission

Turn nwkids.org from a clear program concept into a distinctive, credible, conversion-ready operating site for the First 12.

The site must make one idea immediately understandable:

**Help turn interest into opportunity.**

New World Kids connects a young person's existing interest to a real project, an experienced mentor, paid experience where funding/project structure allows it, visible proof of work, and a next step.

The site must not imply that unconfirmed Seattle partners, mentors, projects, wages, outcomes, or participant results already exist.

## 2. Project lock

### Primary audiences

1. Seattle organizations/businesses with real projects or supervised work environments.
2. Experienced adults who could mentor a participant.
3. Donors/funders who can support the First 12.
4. Youth/referral partners evaluating whether the program is credible and appropriate.

### Primary conversion

**Bring a real opportunity.**

The website should make it easy for a partner to submit one real project, work environment, or mentor opportunity.

### Secondary conversions

- Become a mentor.
- Support the First 12.
- Understand the four pathways.
- Review evidence from Proyecto Indigo Azul and future Seattle projects.

### Protected elements

- First 12 name and Seattle 2027 focus.
- Four-pathway structure.
- Proyecto Indigo Azul name/history.
- Humanitarian Social Innovations fiscal-sponsor disclosure.
- FundRazr campaign destination: https://fundrazr.com/nwkids.org
- English/Spanish localization.
- Existing verified media/provenance rules for Indigo Azul.
- Accessibility and reduced-motion support already implemented.

### What must not happen

- No fabricated impact metrics.
- No fabricated mentors, partners, youth stories, wages, project states, testimonials, or outcomes.
- No generic nonprofit stock photography used as proof.
- No redesign from scratch unless the existing implementation proves unusable.
- No duplicate public source-of-truth sites.
- No new dependency unless the existing platform/native capability cannot solve the problem cleanly.
- No animation whose only purpose is decoration.
- No claim of production readiness without runtime proof.

## 3. Governing brand idea

### Proof of Work

The organization should feel less like a nonprofit describing empowerment and more like a place where young people can point to evidence and say:

**I worked on that.**

The visual/content system should increasingly be built from real project artifacts:

- project briefs
- before/after documentation
- photographs from real work
- screenshots
- sketches
- tools/materials
- hours/dates when verified
- mentor/client notes
- completed deliverables
- next-step records

The system should feel like a deliberate blend of documentary photography, field notebook, work order, youth portfolio, and Seattle civic poster culture.

Do not imitate COLLINS' finished visual work. Apply the rigor: one governing idea, cultural specificity, strong hierarchy, ownable composition, evidence, and system coherence.

## 4. Positioning

### Hero memory

**Help turn interest into opportunity.**

Supporting explanation:

New World Kids starts with something a young person already cares about and connects it to a real project, an experienced mentor, paid experience where possible, and a clear next step.

### First 12

In 2027, New World Kids is starting in Seattle with 12 participants.

The First 12 is a pilot designed to prove the model before expanding it.

### Four pathways

1. **Built for Good — Technology**
2. **Beyond the Game — Sports**
3. **Ground Up — Urban Gardening + Food Systems**
4. **Make Your Mark — Art**

These are four entry points into the same youth-development model, not four separate programs.

### Indigo Azul

Proyecto Indigo Azul is historical/operating proof of the philosophy: young people learn differently when they are trusted with meaningful work in a real place.

It must support the Seattle story without competing with the First 12 as the main program.

## 5. Homepage architecture

The homepage should compress into six deliberate movements.

### 01 / Interest

Purpose: orient immediately.

Must answer:
- What is New World Kids?
- Who is it for?
- What happens here?

Primary line:
**Help turn interest into opportunity.**

Primary action:
**Bring an opportunity**

Secondary action:
**See the First 12**

### 02 / The First 12

Purpose: make the pilot concrete.

Show:
- 12 Seattle participants
- pilot year: 2027
- Interest → Project → Mentor → Next Step
- honest current status rather than implied completion

Future project-status language may include only verified states such as:
- Seeking project partner
- Mentor needed
- Project being scoped
- Opportunity confirmed
- Participant matched
- Project active
- Completed

### 03 / Four pathways

Purpose: show how different interests enter the same system.

Restore Technology as a first-class pathway.

Navigation label should be **Pathways**, not a list of only Sports/Art/Gardening.

Each pathway gets:
- one-sentence purpose
- examples of real work
- what a participant could leave with
- partner/mentor need

Avoid equal-card-wall design if an editorial layout communicates this more clearly.

### 04 / Proof of Work

Purpose: replace claims with evidence.

Initial evidence source:
Proyecto Indigo Azul archive.

Proof module structure:
- year/project
- real image/artifact
- what needed doing
- what participants actually did, only when documented
- result/deliverable, only when documented
- link to fuller archive/case study

Future Seattle proof should use the same structure.

### 05 / Join the work

Purpose: convert organizations and mentors.

Two primary actions:

**Bring a project**

Minimum intake:
- organization
- contact name/email
- what needs doing
- pathway fit: Technology / Sports / Food Systems / Art / Unsure
- whether an experienced adult can work alongside the participant

**Become a mentor**

Minimum intake:
- name/contact
- field/experience
- pathway fit
- availability
- organization/company if relevant

Do not make the user write a generic email unless form delivery is unavailable.

### 06 / Fund the First 12

Purpose: make giving direct and trustworthy.

Explain briefly that donations help cover participant compensation, transportation, materials/equipment, mentor support, and program coordination.

Primary CTA:
**Support the First 12**

Destination:
https://fundrazr.com/nwkids.org

If $25 / $50 / $100 choices all lead to the same generic FundRazr campaign without preserving amount/context, remove the fake-choice layer and use one strong CTA.

Keep the Humanitarian Social Innovations disclosure visible and accurate.

## 7. Design rules

### Priority order

1. User outcome
2. Clarity
3. Trust
4. Ease
5. Speed
6. Accessibility
7. Consistency
8. Delight
9. Visual polish
10. Novelty

### Anti-slop blacklist

Reject:
- generic centered SaaS/nonprofit hero
- default bento grids
- repeated rounded cards
- arbitrary gradients/glows
- random luxury serif choices
- stock lifestyle photography used as credibility
- floating decorative 3D objects
- endless marquees
- arbitrary parallax
- template testimonials
- fake metrics
- decorative AI imagery
- animation on every section

### Typography

- Strong editorial display hierarchy.
- Body text optimized for reading, not visual novelty.
- Control line length.
- Review mobile line breaks manually.
- Avoid excessive bold/all-caps body copy.

### Imagery

Prefer:
- real youth/community work
- Indigo Azul archive
- real Seattle project environments once confirmed
- tools/materials/work surfaces
- real artifacts

Every major image must have a narrative purpose.

## 8. Motion and interaction

Apply Emil/Apple interaction discipline.

Keep:
- immediate press feedback
- short purposeful transitions
- clear spatial origin
- reduced-motion alternative
- controlled image/story reveals

Remove/reject:
- infinite bouncing arrows
- slow intros
- scroll hijacking
- motion that delays reading
- nonessential parallax
- multiple unrelated animation languages

Hero video is conditional on performance.

Hero gates:
- poster appears immediately
- headline/CTA do not wait for video
- reduced-motion users receive a static image
- hidden-page video pauses
- mobile does not unnecessarily download duplicate video streams
- text remains legible over all frames
- video does not materially damage agreed performance budget

If the two-video crossfade fails performance gates, simplify it.

## 12. Execution discipline

### Unlazy

Create an acceptance ledger before substantial implementation.
Every completed gate must be reverified before final release.
Old evidence is not current execution proof.

### Ponytail

For every implementation decision use this order:
1. Does it need to exist?
2. Does the codebase already solve it?
3. Can the platform/native feature solve it?
4. Can an installed dependency solve it?
5. Only then add the minimum new code/dependency.

Never remove validation, security, accessibility, error handling, or user trust to reduce code.

### Ralphy

Execution may be decomposed into bounded tasks/branches/worktrees after this PRD is approved.
Do not use autonomous merging to bypass acceptance gates.

### Gauntlet Loop

Builder and critic must be separate roles/contexts.
Do not self-score to completion.

Primary comparable quality bar:
**COLLINS Girl Scouts strategic/brand system**

Comparison question:
Which experience more quickly and credibly communicates one ownable idea, treats young people with dignity, uses evidence instead of claims, creates a recognizable visual system, and leads the intended audience to a clear action?

NWK does not need to look like Girl Scouts. It must beat the bar on strategic coherence for its own context.
